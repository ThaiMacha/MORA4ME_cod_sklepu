# 🎯 MORA4ME - Cel Projektu (Lokalna Pamięć)

## 🛍️ GŁÓWNY CEL PROJEKTU
**MORA4ME** - nowoczesny sklep internetowy e-commerce oparty na Shopware 6.7 z pełną integracją AI (GitHub Copilot) dla maksymalnej produktywności developmentu.

## 🎨 WIZJA PROJEKTU

### 1. E-commerce Platform
- 🛒 Pełnofunkcyjny sklep internetowy z zaawansowanymi funkcjami
- 📱 Responsywny design (desktop, tablet, mobile)
- 💳 Integracja z systemami płatności
- 📦 Zarządzanie produktami, zamówieniami, klientami
- 🔍 Zaawansowane wyszukiwanie (OpenSearch/Elasticsearch)

### 2. Nowoczesny Development Stack
- 🚀 Shopware 6.7 - najpotężniejsza platforma e-commerce
- 🐳 Full Docker Environment - łatwe wdrażanie i skalowanie
- 🤖 GitHub Copilot Integration - AI-powered development
- 🔧 VSCode Optimization - najlepsze doświadczenie developera

### 3. Architektura Enterprise
```
🌐 Frontend (Twig + Vue.js 3)
    ↕️
⚙️ Backend (PHP 8.4 + Symfony 7)
    ↕️
🗄️ Database (MySQL 8.0 + Redis)
    ↕️
🔍 Search Engine (OpenSearch 2)
```

## 🛠️ STACK TECHNOLOGICZNY

### Backend
- **PHP**: 8.2+ / 8.3+ / 8.4+
- **Framework**: Shopware 6.7 (Symfony 7)
- **Database**: MySQL 8.0 / MariaDB
- **Cache**: Redis 7
- **Search**: OpenSearch 2

### Frontend
- **JavaScript**: ES6+, Vue.js 3
- **CSS**: SCSS, Tailwind CSS
- **Templates**: Twig
- **Build Tools**: Vite, Webpack

### DevOps & Infrastructure
- **Containers**: Docker + Docker Compose
- **Proxy**: Caddy Server

- **Git**: GitHub + GitHub Actions
